Algorithm AlphaBeta(node, alpha, beta, isMax)
If node is a leaf
Return node value
If isMax is True
best = -∞
For each child
best = max(best, AlphaBeta(child))
alpha = max(alpha, best)
If alpha >= beta
Stop exploring remaining children
Return best
Else
best = +∞
For each child
best = min(best, AlphaBeta(child))
beta = min(beta, best)
If alpha >= beta
Stop exploring remaining children
Return best
End
